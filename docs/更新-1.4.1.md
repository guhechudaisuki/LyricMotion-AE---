# 1.4.1：文字到位后静止

## 两个参数

在“整曲设置 → 文字进退场时间”调整：

| 参数     | 范围                                 | 默认 |
| -------- | ------------------------------------ | ---- |
| 进场占比 | 25%～75%，且不超过 100% 减去退场占比 | 35%  |
| 退场占比 | 25%～75%，且不超过 100% 减去进场占比 | 30%  |
| 静止停留 | 两项之外的剩余时间                   | 35%  |

例如一句持续 4 秒，默认进场 1.4 秒、静止 1.4 秒、退场 1.2 秒。各 25% 时停留为 50%；75% / 25% 或 25% / 75% 时没有额外停留。

每句按自身时长计算，保留原始歌词时间。错拍计入阶段窗口，最后一个字也在进场窗口内到位。参数随方案保存，旧方案自动取默认值，切换歌曲风格和随机编排不重置比例。

## 文字运动

去掉到位后的呼吸缩放、缓慢漂移、持续推近和周期性波浪摆动。轻浮、波浪等手法保留在进退场阶段。AE 的到位点与退场起点写入明确的恒定区间，避免两端之间出现插值漂移。

本地文字 FFX 通过独立的可编辑文字子合成暂停源时间。普通字层直接位于逐句合成内；用了文字 FFX 的字层位于“可编辑文字”子合成内。第三方效果插件、字体和依赖原工程结构的表达式仍需在 AE 中查看。

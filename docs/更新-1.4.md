# 映词 1.4 更新说明

这次根据用户的动态歌词视频调整字组层次、留白和字旁运动。普通歌词自动放在两侧，为 MAD / AMV 中间的人物、动作和情绪留出画面。

## 排版与动作

- 新增 28 个排版，总计 140 个。关键词与前后短句分开安排，兼有大小字、竖横组合、错行和逐句接续。
- 新增 4 种文字动作，总计 28 种。保留固定遮罩中的进场和退场、逐字错拍等动作。
- 根据实际字体测量整组宽高，再调整占比和安全位置。整组靠侧时，普通文字运动也受内侧边界限制。
- 高亮按真正的关键词范围处理，大字号不再自动把整条正文染色。
- 主词前后的小句保留原有语序，中文换行尽量避免孤零零的单字。

## 字旁元素

- 新增 12 种，总计 48 种：丝线绕字、轻弧双掠、花瓣随弧、菱光循线、角落连星、两岸月弧、细弧流星、断续银线、字畔微尘、疏星错闪、浮动珠光、双叶轻摇。
- 星光逐个明灭，线上的小物各自运动；入场略晚于正文，结束时随歌词退场。
- 环绕元素依据字组实测边界展开，不使用固定画布中心。底线跟随正文底缘；局部元素检查已占位置，空间不足时缩小或省略。
- AE 使用形状路径、透明度、描边和变换关键帧，文字继续保持可编辑。

## 面板

整曲设置增加“关键词字体”和“画面占比”。默认风格仍为“完全随机 · 无固定风格”；歌曲分类、自建集合、任意多选预设和内置风格保护继续沿用原有逻辑。

SRT/LRC 时间、手填 `歌词|副标题`、可选整曲翻译与持久缓存、预渲染后导入 AE 项目的流程保持原有功能。

## 演示与交付范围

- `docs/动效演示.html` 可拖动时间或更换排版、动作、元素。
- `reference/1.4-preview/面板动效演示.mp4` 为 32 秒面板引擎演示；背景、说明标签、时间条不属于实际歌词输出。
- 本次使用源码审阅、静态语法解析、面板演示渲染和安装文件哈希核对；没有启动 AE，没有调用真实翻译 API，没有运行功能测试。实际 AE 字体、第三方预设和生成效果由用户在工程里体验。

安装器：`dist/映词-LyricMotion-AE-安装器.exe`。安装后自行重新打开映词面板；若 AE 保留了旧脚本，请自行重启 AE。

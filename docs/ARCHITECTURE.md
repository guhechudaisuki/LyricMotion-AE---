# 架构

## 数据流

歌词通过 `LMCore.parse` 转成带起止时间的 cue。整曲设置和已保存随机种子进入共享布局引擎，得到文字、线条、元素及其运动描述。Canvas 使用实际字体测量预览，AE 适配器通过 `sourceRectAtTime` 测量图层，再运行共用的几何整理。

面板通过 ASCII JSON 编码调用 `LMHost.dispatch`。长生成任务分批执行 `begin` / `step` / `cancel`，避免单次任务长时间占住面板。预渲染使用一次性模板选择标识，清理临时渲染队列并恢复原队列开关。

## 兼容边界

- `shared` / `host`：ES3。构建时用 Acorn 校验，并处理 ExtendScript 的正则字符类斜线差异和非 ASCII 编码。
- `panel`：CEP / 浏览器 JavaScript，ES2020 语法上限；浏览器独立预览不提供 AE 操作。
- `node`：CEP 内置 Node 能力，仅负责文件操作及结构化资源路径处理。
- `scripts`：Node.js 24 开发工具，不打入面板。

## 资源

发布目录由相对路径索引及锁定哈希连接。安装器先校验本地 resources，跳过已存在且 SHA-256 一致的文件；只从固定 Git 提交下载缺失或损坏文件的 gzip 对象。内容相同的文件只下载一次。全部下载校验后补全缺失文件；失败保留已验证下载缓存，重试可继续。下载器随 EXE 提供，不执行远程脚本。

FFX 直接解析安装路径；需要外部素材的 AEP 只重写 RIFX 容器中已知结构内的 JSON 文件别名。在导入前生成缓存副本，原默认资源不写入本机绝对路径。自建风格保存相对资源路径，实际调用前复制并解析，不修改用户方案。

## 持久化

方案文件保存歌词时间、风格、随机种子与人工副标题。设置与自建风格使用 CEP 本地存储；翻译按主歌词及目标语言保存在 IndexedDB，默认最多 500 首，按最近使用顺序淘汰。API Key 只在当前面板会话内存在，不进入方案、日志或翻译缓存。

## 验证边界

单元检查可验证纯逻辑和模拟 AE 对象的行为，面板检查覆盖真实 DOM 事件到桥接的流程。它们不能证明实际 AE 的字体、第三方控件及渲染输出表现。

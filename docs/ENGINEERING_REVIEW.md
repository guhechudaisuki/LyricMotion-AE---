# 1.5.0 工程检查记录

日期：2026-10-04。检查围绕正确性、可读性、模块边界、输入与凭据安全、资源开销展开。

## 已处理的问题

| 问题                                     | 处理                                                           |
| ---------------------------------------- | -------------------------------------------------------------- |
| 构建、演示与检查脚本引用旧目录           | 统一目录清单、重写分发构建、独立测试夹具                       |
| 本机工具和精选库使用固定盘符             | 工具使用 PATH / 环境变量；个人配置移入忽略目录                 |
| 预设路径只在作者电脑有效                 | 发布相对路径索引、安装位置解析及自动风格解析                   |
| AEP 引用原素材位置和主机名               | 结构化别名改写；463 条素材引用及对应文件校验                   |
| Symbols 原合集缺少皇冠序列               | 按用户要求排除该合集，未用其他动画替补                         |
| 进场和退场预设文件重新命名后无法成对匹配 | 单独保存稳定的配对键                                           |
| 重装重复下载资源                         | 按 SHA-256 验证本地文件，缺失/损坏才下载，相同内容只取一次     |
| 下载中断重新开始                         | 保留已验证对象缓存；重试复用，错误包不覆盖已有文件             |
| PowerShell 网络栈在本机无法连接          | 使用系统 curl，保留 TLS 校验；支持系统代理，限制并发与下载大小 |
| 格式不统一、未使用变量与重复声明         | 全量 Prettier、ESLint；修复问题，兼容例外限定到特定运行时      |
| 对输入对象直接调用 hasOwnProperty        | 改为 Object.prototype.hasOwnProperty.call                      |
| 打包版本和目录不一致风险                 | 构建前检查元数据，NSIS 版本从 package.json 传入                |
| 旧版安装遗留个人路径索引                 | 成功升级后清理明确列出的旧平铺模块                             |

## 验证证据

- `npm run check`：全量格式、静态检查、33 项单元回归、公开文本路径/凭据扫描和源码构建通过。
- `npm run test:panel`：4 项预渲染真实面板流程（模拟 AE），4 项 IndexedDB 缓存检查通过。
- `npm run test:installer`：首次下载、本地复用、同内容复用、损坏修复、失败保留旧文件共 5 项通过。
- `npm run resources:verify`：522 项精选预设、8,306 个文件 SHA-256、463 条 AEP 素材引用通过。
- 使用正式固定 GitHub 提交下载 FFX、AEP、PNG 三类资源；再次运行复用全部 3 项，网络下载为 0。
- NSIS 3 在线安装器编译通过，资源不是 Release 附件。
- 正式 EXE 静默安装两次：首次补下载 3 个缺失资源、复用 8,303 个；再次复用全部 8,306 个、下载 0 个。安装后 30 个插件文件和 8,306 个资源文件哈希一致，旧版平铺索引已清理；未启动 AE。

## 限制

本次没有启动或控制 AE。模拟对象和 Canvas 不能替代真实 AE 的字体、Pseudo 控件、AEP 导入以及最终渲染验收。第三方资源授权信息单独列在 `THIRD_PARTY_NOTICES.md`，没有将其错误声明为项目自有资源。

1.0.0–1.4.2 的历史安装包和源代码快照未找到。相关 Release 只归档可核实的更新记录。

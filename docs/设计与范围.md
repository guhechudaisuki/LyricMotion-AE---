# 映词 LyricMotion

独立 AE CEP 扩展，项目位于 独立工程目录。不替换 JIZURA，也不写入其安装目录。

## 参考观察

用户提供《歌词排版｜颜人中「我只能离开」》。参考视频为 1280×720、25 fps、230.14 秒；以时间采样帧观察了全片及重点句。

- 局部歌词组占画面较小面积，主要靠左或靠右，给主体留下空间。
- 细宋体／衬线中文字，关键词大小错落，前后短句以小字陪衬。
- 白字、低饱和蓝灰画面、极少的短横线；变化主要来自排版与细微动态。
- 轻微模糊显影、逐组位移和透明度变化。输出不加入参考水印、品牌字或镜头序号。

## 功能

- 112 个内置排版预设：原有 64 个基础排版，新增 12 类共 48 个运动排版；另有 24 个文字动作与 36 种动态字旁元素。
- 默认透明合成；画面／背景仅供面板预览，不烘焙进生成的歌词。
- SRT、LRC、普通歌词导入；保存每句起止时间，允许编辑注释、关键词、风格和位置。
- 真实 AE 文字层与形状层；每句独立预合成，整曲主合成保留原时间轴。
- 默认完全随机、无固定整体风格；随机种子保存。歌曲动效风格沿用原 PV 工具的六个歌曲分类：慢歌抒情、极简叙事、流行轻快、摇滚燃曲、电子舞曲、电影感。分类共同约束排版池、进出场动效、停留动态、速度、强度、字旁元素数量与搭配，支持分类内一键随机。完全随机、歌曲分类和自建风格同属一个下拉入口；排版手法和位置另设。
- 自定义风格是现有排版、字旁元素、FFX/AEP/媒体的任意多选集合，可编辑或删除；内置风格不可删除。
- 放大关键词和高亮关键词独立设置；支持多个高亮词、逐句开关、整体大小反差与高亮颜色。AE 中高亮保留为可编辑文字动画器。
- 本地预设索引、目录扫描和应用到 AE 所选图层。预设可进入自定义集合，按文字/字旁角色随机搭配。只引用本机文件，不打包第三方资产。
- AE 原生预渲染，优先带 Alpha 的视频输出模块，渲染完成后导入当前项目。
- 独立中文 NSIS 安装器。

## 面板设计

深蓝灰底 #181E27，控件 #242D39，边线 #354253，正文 #E5EBF1，次级字 #9EAFC2，强调 #A6C8DF。
界面使用微软雅黑；排版示例使用宋体，关键字与细小旁白构成风格卡片。主预览先于设置，停靠窄面板时纵向排列；无手机版入口。

## 检查约束

不启动 AE。实现后做代码审查、静态语法检查、构建和安装文件核对，不新增或运行功能测试。生成面板引擎的动作演示与界面截图作为可查看的交付物；实际 AE 渲染效果由用户自行体验。

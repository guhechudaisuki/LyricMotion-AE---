# 映词 LyricMotion 使用指南

独立的 After Effects 动态歌词面板，面向 MAD / AMV 画面叠字。Windows，AE 2022 或更高版本。项目与扩展 ID 独立于 JIZURA。

## 1.5.1 自选安装位置

安装器提供一个目录选择项：插件和 resources 一起存放在所选文件夹，自动在 AE 标准扩展目录建立入口。升级时默认显示上次位置，也可改到新的专用目录；已有资源会先校验复用。完成页显示最终安装位置。卸载只清理插件自带文件，保留额外添加的文件。

## 1.5.0 安装与默认资源

Release 提供 `LyricMotion-AE-1.5.0-setup.exe`，运行后自动检查安装目录的 resources，只下载缺失或损坏的资源。用户无需单独运行 PowerShell、安装开发工具或下载资源包。包含 522 项精选预设（503 FFX、19 AEP）及其预览和工程实际引用的素材；缺失素材的 Symbols 合集已排除。

安装当前版本后，重新打开面板，顶部应显示 1.5.1。默认库使用相对路径，可在其他电脑使用。旧方案引用的个人素材仍需用户自行保留；自加素材移动后需重新扫描。

## 1.4.3 预渲染模板报错修复

针对预渲染中出现的“? Alpha / ??? 不是有效的模板名称”：模板名称留在 AE 宿主内，面板改为传递选择编号；双方 JSON 使用 Unicode 转义，避免中文名称经过旧编码边界时丢失。应用模板后重新获取输出模块，失败或取消时清理本次临时队列项并恢复原有队列勾选。新增“当前 AE 默认输出设置”，可沿用新建渲染队列项的默认设置。

此修复保留在 1.5.0 中。已有工程、歌词方案和风格库保留。详见 [1.4.3 自检记录](更新-1.4.3.md)。

## 1.4.2 字组间距与字旁元素

“右岸错层”收紧大字与后续小句之间的距离，其他排版保留原有文字疏密。12 种字旁元素改为短弧、细叶、实心星光和碎光；按关键词的实际字形外框摆放，竖排按单字高度计算距离，不再围着整块字幕画大框。旧有小元素和自动搭配的本地媒体也靠近关键词，并避让邻近文字；无空间时缩小或跳过。

默认自动位置以每两句为一组，随机选择左右顺序，每组各占一侧，避免整首落在同一边。手动指定某句位置仍优先。自选风格可多选小元素、左右位置、退出手法、正文字体、关键词字体、配色和高亮方式；字体与配色在所选范围内为整曲选一套。见 [1.4.2 更新说明](更新-1.4.2.md)。

## 1.4.1 进场、停留与退场

整曲设置 → **文字进退场时间**：进场和退场各占本句时长的 **25%～75%**，两项合计最多 **100%**。拖动范围随另一项调整，不能挤掉另一项的最低 25%。默认进场 **35%**、退场 **30%**，剩余 **35%** 静止停留。面板同时显示当前一句各阶段的秒数。

逐字、逐词和分行错拍包含在各自窗口内，到位后不再呼吸、漂移、推近或持续波浪摆动。合计 100% 时直接衔接进退场；不会额外增加停留或改写歌词开始、结束时间。比例随方案保存，随机编排和切换风格会保留比例；旧方案没有这两个参数时使用 35% / 30%。

选用本地文字 FFX 时，可编辑文字放在同名子合成中，外层通过时间重映射暂停文字效果的时间。双击“可编辑文字”进入即可修改字层。第三方预设的具体字形、入退场形态与上下文表达式仍以 AE 中的结果为准。

## 1.4 字组与字旁元素

- 140 个内置排版。本次新增 28 个词组排版，包含大小字错层、竖横混排、前后短句、错行和短章；保留逐字/逐词/分行遮罩、交错快门、字距开合等运动排版。
- 普通歌词默认在左或右侧，按整组字形边界避开画面中央。侧边字组可以展开至约三分之一画宽；未显式指定位置时不会随机落到画面中心。左右区还限制文字运动的内侧范围。手动指定位置继续有效。
- 28 种文字动作，新增错层接句、书页转入、收幅展开、弧线落位。可整曲指定，也可覆盖某一句；自定义风格可以任意多选“文字动作”。
- 文字穿过固定遮罩后归位，再进入遮罩离开。AE 保留文字层、遮罩、文字动画器及可编辑关键帧。
- 48 种原生动态元素，新增独立明灭的疏星、字旁弧线、沿线菱光/花瓣、月弧、珠光等。环绕线以实际字组边界定位，元素较正文稍晚出现；空间不足时先缩小局部元素，仍放不下则省略该处。每句元素数量是上限。
- 排版按实际字体边界安排间距，逐字排版给大字留出宽度；AE 先测量文字再排版、写动画。相邻文字与副标题遇到冲突时自动让位。中文主词尽量不跨行拆开。
- “关键词字体”可自动随排版配合行楷/宋体，也可统一指定或与正文保持相同。“画面占比”可选自然变化、大字展开、小字留白；放大仍受左右留白和安全边界约束。
- 随机先轮换排版手法，再抽取该手法里的变体；动作与元素也使用轮换抽取，减少连续重复。歌曲分类仍沿用原 PV 的六分类，默认完全随机。
- 当前默认库有 522 项精选预设（503 FFX、19 AEP），查看历史选型记录见 [本地动效精选](本地动效精选.md)。进入/离开 FFX 仅在用户选择的集合内配对。

源码提供[可交互选型页](动效演示.html)。演示由同一套面板引擎生成，并非 AE 渲染。演示页的标签、背景不会加入歌词合成。参考记录见[参考与排版方向](参考与排版方向-1.4.md)。参考视频和开发期间生成的演示视频不随发布提供。

## 安装与打开

运行从 [Release](https://github.com/guhechudaisuki/LyricMotion-AE---/releases/latest) 下载的 `LyricMotion-AE-1.5.1-setup.exe`，选择插件和 resources 的存放目录。安装器自动建立当前用户的 Adobe CEP 扩展入口。自行重启 AE，在 **窗口 → 扩展 → 映词 LyricMotion · 动态歌词** 打开。

AE 首选项 → 脚本与表达式：启用“允许脚本写入文件和访问网络”。建议面板宽度 1000 像素以上，可停靠；没有手机版。

## 歌词工作流

1. 导入 SRT、LRC 或粘贴歌词。SRT 开始/结束时间保留；LRC 结束时间取下一时间戳，最后一句默认 4 秒。纯文本每句 4 秒，可再编辑。
2. 载入音乐；“载入画面”只用于检查字幕与背景的关系，生成合成保持透明。
3. “歌曲动效风格”采用原 PV 的歌曲分类：**慢歌抒情、极简叙事、流行轻快、摇滚燃曲、电子舞曲、电影感**。完全随机和用户自建风格也在同一下拉框。默认完全随机；随机种子随方案保存。
4. 分类同时约束可选排版、进出场手法、运动幅度与装饰数量。进退场时长按下方比例设置。“随机编排”保持当前歌曲分类与配色；“一键随机”同时改变编排、字体、配色和动作。选择歌曲类型后按钮变为“按歌曲风格生成”，始终在该分类内搭配。140 个排版可按排版手法筛选或只看收藏；点击可手动指定当前一句，本句也可改回“跟随整体设置”。
5. 在“当前一句”编辑主歌词、副标题、放大关键词和高亮关键词。高亮词可多个，用逗号分隔。大小对比排版中的主词可调整“关键词放大”。简洁单行排版保留统一字号，可用局部高亮。
6. “自动突出”只在部分句子用高亮，避免整曲每个字都抢眼；本句可指定始终高亮或关闭。默认高亮为淡蓝色，可换色。
7. “生成 AE 动态歌词”：先确认 AE 连接，再按图层分批生成，显示句数和当前图层进度。每句独立预合成，内部文字为可编辑 TextLayer，小元素为 ShapeLayer；高亮为文字动画器的填充颜色范围。完成后 AE 时间指针跳到首句可见的位置。没有镜头序号、水印或自动添加的装饰英文。

输入也支持 `主歌词|副标题` 和 `*放大关键词*`。示例 SRT 来自用户提供的《我只能离开》42 句原始时间轴，末句为 03:42.509–03:46.509（假定持续 4 秒）。没有捆绑音乐和参考视频。

## 可选的副标题翻译

顶部“设置”中填写 OpenAI Chat Completions 兼容接口地址、模型、API Key 和目标语言。自动翻译**默认关闭**；地址、模型与偏好保存在本机，Key 仅在本次面板会话中使用，不写入方案、缓存或安装器。

- `歌词|手填副标题`：始终使用手填内容，不会覆盖。
- `歌词|`：明确将这一句副标题留空，不自动补译。在当前一句的副标题输入框手动清空也表示留空。
- `歌词`：仅在开启翻译且当前排版需要副标题时取用译文。自动补译用于“双语落款”和“边侧注记”排版；其他排版里的小字是主歌词的一部分。手填副标题不受排版类别限制。

生成前先查本地缓存；缺少目标语言时，将**整首主歌词合并为一次请求**，要求模型按固定 ID 返回 JSON，脚本截取并完整检查数量、ID、分行与长度后才使用译文。只把需要的行填入画面，保留所有原始时间。关闭翻译会移除当前自动副标题，手填副标题保留。失败、取消或未配置接口时，未填的副标题保持为空，AE 歌词生成继续；点击主界面的“停止生成”会同时停止整个生成流程。同一失败批次在本次会话不会自动重试，可在设置中手动重试。

译文通过 IndexedDB 持久保存在本机，默认 **500 首**，设置中可调整为 1–10000 首。歌曲按有序主歌词内容识别，改标题、时间或排版可复用；同一歌曲的多种目标语言合计一首。每次命中更新使用顺序，写入新歌曲超限时淘汰最久未使用的歌曲，降低上限并应用会立即淘汰超额条目。已淘汰的歌曲下次需要翻译时会重新请求；修改主歌词或增加目标语言也需要对应的新译文。模型/API 地址变化不自动清除已有译文。

面板预览会读取已缓存译文，不会因播放、随机编排或导入歌词自动发送网络请求。“准备本曲副标题 / 手动重试”可在设置中提前准备。为避免回复截断，一次翻译最多 300 句、主歌词 UTF-8 总计 24 KB，超限时不请求且保持空白；不会暗中拆分多次请求。缓存写入失败会明确提示，当前会话仍会复用成功译文。

## 添加自己的风格

“添加风格”打开多选集合：内置排版、28 种文字动作、48 种动态字旁元素、本地 FFX/AEP/视频/图片，以及退出手法、左右位置、正文字体、关键词字体、配色、高亮方式，任意数量。可以搜索、全选结果、逐个取消，保存后可编辑或删除；内置风格无删除入口。手动修改整曲字体、颜色或高亮时，当前方案中对应的随机范围清空，采用手动值；已保存的风格库不受影响，重新选择该风格可恢复集合。

保存的集合会立即加入“歌曲动效风格”下拉框；“我的风格”标签页负责编辑和删除集合。

### 内置歌曲分类

| 分类     | 自动搭配规则                                      |
| -------- | ------------------------------------------------- |
| 慢歌抒情 | 柔和显影、缓慢消散，到位后静止，最多 1 个字旁元素 |
| 极简叙事 | 清楚阅读、平稳淡入淡出，无字旁装饰                |
| 流行轻快 | 轻弹、逐字错拍，少量星点与花瓣                    |
| 摇滚燃曲 | 主词对比、快速收放和短促位移，最多 2 个元素       |
| 电子舞曲 | 阶梯式显字、疏密字距、几何元素                    |
| 电影感   | 细宋体和大字、柔和入退场，到位后静止              |

这些动态作用于歌词本身，生成透明叠加合成。原有 1.1 的配色名称自动迁移为对应歌曲分类；收藏继续保留在预设库，自建集合继续保留。

每句在选中集合内抽取排版与动效。没有选择排版时用靠侧简洁短句，没有选内置元素时不额外随机加入。FFX 可指定作用于文字或字旁形状；字旁 AEP 需在面板中指定内部合成，会导入该工程以供选择。文字 AEP 是手动模板入口：导入后打开真实合成替换歌词，不加入自动字旁集合。媒体每句最多搭配一个，默认小尺寸和淡入淡出，黑底可选择滤色。

文字 FFX 自动搭配保留歌词内容、字号/配色和排版，保留预设内部文字动画器/效果。装饰 FFX 的变换动画和透明度保留在素材图层，另用定位空对象放到歌词旁；原生描边和路径运动继续写入形状。IN/OUT 只从已选集合内配对，没有选 OUT 就不会自行加选。第三方 FFX 可能需要另外安装字体或效果插件，实际结果以 AE 为准；失败会列入生成结果提示。

## 本地素材库

1.5.0 的精选预设、预览和工程实际引用的素材由安装器自动下载。你也可以扫描自己的文件夹；自加素材移动后需重新扫描并更新风格集合。压缩包与 FXM 容器需要通过原素材工具解压或安装后再扫描。

FFX 按名称推测用途，请在集合中检查“作用于文字/字旁形状”。缩略图可用时显示原库预览。Canvas 展示内置排版、大小和高亮；本地 FFX/AEP 的实际动效在 AE 中查看。

发布版只含所选默认资源的相对路径索引；开发者个人素材盘的完整清单不包含在安装器或源码仓库中。

## AE 连接和任务恢复

连接完成前生成按钮暂时不可用。点击生成后，面板先显示连接状态；按图层分批更新进度，不再等待整句完成才刷新。静止属性不写重复关键帧。

如果 AE 长时间没有回应，面板会显示等待时间，并在 45 秒后提示检查 AE 弹窗及重新连接。超时不会自动重复提交生成。重新连接后可继续未完成的任务、停止任务，或识别已经完成的结果。若从 1.0 更新且存在旧任务，会先结束旧任务并保留已完成的歌词，再载入新版脚本。

调用状态记录在 Windows 临时目录的 `LyricMotion-AE-bridge.log`，不记录歌词文本。第三方 FFX/AEP 单次原生调用仍可能花较长时间，分批只在原生调用返回之后继续。

## 保存与预渲染

“保存方案”生成 JSON，包含歌词时间、逐句设置、高亮、随机种子及自定义风格。编辑时自动保存到面板本地存储；大型集合请保存文件。SRT 仅保存歌词、副标题和时间，视觉设置用 JSON 保存。

“预渲染”直接编码面板当前歌词动画，不需要先生成 AE 文字图层，也不渲染当前打开的 AE 合成。可选 MOV（无损，支持透明）或 MP4（H.264，需有背景），支持 23.976、23.997、29.97、59.94 等小数帧率。背景直接使用预览时选好的底图或载入画面，导出窗口不重复设置。预览选透明底时使用 MOV；MP4 会提示先修改预览底图。辅助线不写入视频。音乐可勾选包含，MOV 使用 PCM，MP4 使用 AAC；编码能力不足会提示选择其他格式。面板预览之外的第三方 FFX/AEP 实际效果仍通过“生成 AE 动态歌词”使用。

视频放在 AE 项目旁的 `LyricMotion预渲染` 文件夹；未保存工程时放到“文档”。完成后自动导入 AE 项目并创建视频合成，可直接拖入其他合成，时间指针定位首句。保持面板打开，过程中可点“停止预渲染”；取消只移除未完成的视频文件。导入失败保留已完成视频并显示位置。

## 当前交付验证范围

1.5.0 检查包括全量格式与静态检查、33 项单元回归、4 项实际面板预渲染流程（模拟 AE）、4 项持久化翻译缓存检查、5 项安装资源流程，以及 8,306 个资源哈希和 463 条 AEP 素材引用。正式 EXE 已验证缺失资源下载和重复安装复用。没有启动或控制 AE，没有运行真实 AE 渲染。Canvas 与 AE 使用同一布局和运动参数，分别以实际字形边界居中；不同字体替代、第三方预设与 AE 版本仍需在实际工程中查看。

## 源码构建

开发需要 Node.js 24。运行 `npm ci`、`npm run check`，即可检查并构建源码。Windows 上运行 `npm run tools:extendscript` 获取固定版本、校验 SHA-512 的独立 ExtendScript 编译工具，再运行 `npm run test:extendscript` 检查实际宿主脚本；此过程不会启动或连接 AE。工具来自 `jsxbin@2.3.0` 所携带的 Adobe 编译器，仅存于被忽略的 `.local/tools`，不随插件分发。也可通过 `EXTENDSCRIPT_COMPILER_PATH` 指定已有的 `esdcorelibinterface.node`。CI 和 `npm run package` 都会执行原生编译检查，通过后才使用 NSIS 3 生成在线安装器。

默认资源按固定提交单独存放，开发者可运行 `npm run resources:fetch` 获取，用户安装时由 EXE 自动完成。构建时补全 ExtendScript 嵌套条件表达式所需的括号、转换正则字符类斜线，并作 ES3 静态解析。资源安装完成后，歌词排版可离线使用；只有开启自动翻译且缺少所需缓存时才需要配置的在线服务。

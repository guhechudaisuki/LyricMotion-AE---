# 映词 LyricMotion 1.3

## 动态排版和元素

- 内置排版由 64 个扩展为 112 个，增加 48 个实际进退场编排；共 24 种文字动作、36 种动态字旁元素。
- 文字可从固定遮罩内进入、退出，支持逐字/逐词显字、开合、折叠、字距聚散、波浪、摆动、弹性和模糊位移。
- 元素保留可编辑路径，带描绘/擦除、转动、微粒、脉冲等运动。
- 按实际字体测量文字，先处理重叠和边界再写动画；关键词大小、高亮和原始时间保留。
- 先选排版家族再打乱，减少连续抽到相似排版和动作。
- 从 用户提供的预设库 中精选 18 组、523 个文件，含 503 个 FFX 和 20 个 AEP；520 个匹配预览。引用原路径，不随安装器分发第三方素材。
- 文字 AEP 作为手动打开、替换文字的模板；自动字旁集合不插入含原始模板英文的文字工程。
- 文字 FFX 的 IN/OUT 按已选集合配对；装饰 FFX 保留图层变换，另由空对象放在字旁。

## 副标题与整曲翻译缓存

- 所有 API 和翻译选项放在顶部“设置”，自动翻译默认关闭。
- `歌词|副标题` 保留手填；`歌词|` 明确留空。仅没有 `|` 且排版需要副标题的行使用自动译文。
- 自动副标题只出现在“双语落款”和“边侧注记”；手填副标题可用于任意排版。
- 整首歌词一次大模型请求，按 ID 截取、完整验证 JSON 后写入，不分句请求、不自动修复请求。
- 失败保持空白并继续生成；当前会话同批失败不会自动反复请求。
- IndexedDB 本地缓存默认 500 首，上限可调。歌曲按主歌词匹配，多个目标语言计为一首；超限按最久未使用顺序淘汰。
- 时间、标题和排版变化复用译文；手填和自动副标题分开记录。API Key 仅在面板会话中使用。

## 交付边界

动效演示由实际面板 Canvas 引擎生成，位于 `reference/1.3-preview/面板动效演示.mp4`。文字与 AE 共用布局和运动描述，但 Canvas 演示不是 AE 实机渲染。

没有启动 AE，没有真实调用大模型 API，没有新增或运行测试。静态检查、构建和安装记录见 `dist/install-receipt.json`；最终字体替代和第三方 FFX/AEP 兼容性由用户在 AE 工程中查看。预设中的 Pseudo/ 控件可能需要安装原素材包；装饰 FFX 的非均匀缩放与旋转叠加可能仍需手调。

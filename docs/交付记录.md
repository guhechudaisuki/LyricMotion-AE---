# 交付记录 · 2026-10-02

本文记录初版 1.0；当前 1.3 的修改见 `更新-1.3.md`，1.1 历史修改见 `更新-1.1.md`，最新文件清单与哈希见 `dist/build-files.json`。

## 已实现

- 独立 AE CEP 面板，`com.lyricmotion.ae.panel`，仅 AEFT。
- 16 个内置排版、8 个整体风格、14 种原生字旁形状；默认从全部排版随机选择，无预设整体风格。
- 歌词主次字号、放大词、独立高亮词（可多个）、高亮颜色和逐句开关；Canvas 与 AE 共享范围计算。
- 原时间轴 SRT/LRC、逐句编辑、副标题、音乐与画面预览、JSON 保存/打开、本地自动保存和编辑撤销。
- 用户自建风格为任意预设多选集合，可编辑/删除；内置不可删除。
- 本机索引：15965 个 FFX、4250 个 AEP、22865 个媒体条目；802 项匹配到原库预览图。路径索引不是兼容性认证。
- 批量 AE 可编辑文字/形状生成、可中止、原生预渲染后自动导入项目与新建视频合成。
- 中文 NSIS GUI 安装器与独立卸载项。

## 源码审阅修正

- 坐标缺省值不再把 null 当成 0；整组缩放同时缩放路径顶点和描边。
- 关键词跨换行、错行或单字图层拆分时仍计算局部高亮。
- 文字创建时清除 AE 上次使用的字符/段落样式，再按共享参数设置；按实际字形边界居中。
- 预渲染保存并恢复其他队列项原有 render 布尔值，完成后移除临时已完成队列项。
- 明确拒绝空白歌词，媒体放置带位置兜底，过期渲染目标不会静默切换到另一合成。
- 修正原生分发函数语法；本地缓存校验数组类型，避免损坏缓存导致面板启动失败。
- 审阅曾建议把 AE 文本索引加 1；经现有脚本与属性模型核对，该建议被撤回，保持 0 基半开范围。
